SCM · Warehouse Management: Release digest

Covers: Warehouse Management 26D
Oracle updated: 30 Sep 2026 · Source: Oracle Cloud Readiness

Executive Summary

The 26D release of Warehouse Management brings a host of new features and enhancements aimed at improving usability and operational efficiency. Key highlights include the introduction of a 3D warehouse inventory visualizer, expanded Redwood Desktop capabilities, and enhanced reporting features that provide better visibility into operations. Additionally, clients must transition from SOAP to REST API integrations for FedEx and UPS, and migrate from.xls to.xlsx formats for input interfaces. These changes are crucial for maintaining compatibility and leveraging new functionalities effectively.

What's New

  • The Warehouse Visual Layout feature provides an interactive 2D and 3D visual representation of the warehouse layout, enhancing decision-making regarding location capacity and utilization. (3D warehouse inventory visualizer)
  • The Redwood experience has been expanded to include new screens such as Clock View and Dashboard View Gen 2, improving usability and navigation within the WMS Redwood Desktop. (Expanded Redwood experience for desktop)
  • A new report execution audit dataset enhances visibility into Web Report usage, capturing details such as who ran reports and their execution status. (Web Report usage visibility)
  • Label Designer V2 introduces a modern web-based label authoring experience, allowing faster creation and maintenance of production-ready labels with dynamic content creation. (Next Gen Label Designer)
  • The Warehouse Execution Command Center is introduced as an AI-powered operational workspace for warehouse supervisors, focusing on outbound transactions and providing insights into at-risk orders and picking bottlenecks. (AI Agentic App: Warehouse Execution Command Center)
  • A new prebuilt integration for inventory reconciliation using file-based processing allows WMS to fetch ERP on-hand and serial number information for serial-tracked items. (New prebuilt integration for inventory reconciliation using file-based processing)

What's Changed

  • The Mobile Load OBLPN transaction now honors the facility parameter ASSIGN_NEWLOAD_AT_CLOSE, preventing users from closing a load if assigned OBLPNs are not loaded. (Expand mobile Load LPN transaction to honor load related facility parameters)
  • Administrators can now control access to the 'Launch Mobile App' link in the Desktop UI, promoting the use of approved handheld devices by restricting access for specific user groups. (Restrict launch mobile app access from desktop)

Deprecations, Retirements and Replacements

  • SSH-based RF will be deprecated starting January 2026, replaced by Redwood Mobile WMS. (IMPORTANT Actions and Considerations)
  • Support for.xls format will be deprecated in 26D; clients must switch to.xlsx format for input interfaces. (IMPORTANT Actions and Considerations)
  • Warehouse Management: Legacy Designer planned for deprecation in a future release. (Next Gen Label Designer)

Action Required

  • Migrate to REST-based carrier integrations for FedEx and UPS to ensure continued functionality. (IMPORTANT Actions and Considerations)
  • Follow instructions to migrate attachments to OCI Object Store to comply with new storage requirements. (IMPORTANT Actions and Considerations)
  • Switch from.xls to.xlsx format for input interfaces to avoid disruptions after the deprecation of.xls support in 26D. (IMPORTANT Actions and Considerations)
