SCM · Inventory Management: Release digest

Covers: Inventory Management 26D
Oracle updated: 2 Oct 2026 · Source: Oracle Cloud Readiness

Executive Summary

In the 26D release of Inventory Management, several new features and enhancements have been introduced to streamline operations and improve inventory management. Key highlights include the ability to enable intra-organizational material transfers for supply requests, enhanced mobile inventory functionalities, and AI-driven tools for task allocation and packing recommendations. Customers are encouraged to opt in to new features and perform necessary setup tasks to leverage these capabilities effectively. Additionally, the release emphasizes improved compliance through electronic records and signatures for various transactions, ensuring better audit trails and operational transparency.

What's New

  • Supply Chain Orchestration now enables intra-organizational material transfers for supply requests originating from Self Service Procurement, improving fulfillment flexibility and inventory utilization. (Enable intra-organizational material transfers for transfer supply requests originating from Self Service Procurement)
  • Oracle Supply Chain Orchestration supports capturing inventory on hand striping attributes, such as grade, for manual transfer supply requests, enhancing fulfillment precision. (Inventory on hand striping attributes for manual transfer supply requests in Supply Chain Orchestration)
  • The Inventory Task Allocation Assistant AI agent can automatically assign receipt delivery tasks to robotic material handling equipment, optimizing resource allocation. (Inventory Task Allocation Assistant - Assign tasks to robotic material handling equipment)
  • The LPN Packing Advisor AI agent provides data-driven packing recommendations during put away transactions, improving operational efficiency. (LPN packing advisor)
  • Users can now approve physical inventory adjustments in bulk using a spreadsheet, enhancing efficiency in inventory management processes. (Approve physical inventory counts using a spreadsheet)
  • Dynamic locator creation allows users to generate valid storage locations on the fly during transactions, enhancing flexibility in warehouse operations. (Use dynamic locator creation)
  • The Generate Changed Receipt Advice feature allows users to communicate purchase order quantity changes to integrated WMS or 3PL systems, improving receiving operations. (Communicate additional purchase order changes to a WMS or 3PL using generate changed receipt advice)
  • AI-assisted recall notice creation from email attachments automates the processing of supplier recall letters, reducing manual intervention. (AI-assisted recall notice creation from email attachments)
  • The default cost organization is now carried forward across various Cost Accounting pages, reducing the need for repeated selections. (Default cost organization across Cost Accounting pages)
  • Users can now model their own SQL queries as custom business object queries against the Read-Optimized Data Store for faster data extraction. (Support for user-defined queries in data extracts)

What's Changed

None identified in this release.

Deprecations, Retirements and Replacements

None identified in this release.

Action Required

  • Customers must perform pre-update and post-update tasks as required by their Cloud applications before and after the quarterly update. Refer to Oracle Fusion Cloud SCM: Performing Your Quarterly Update for specific details on affected product areas. (Pre-Update and Post-Update Tasks)
  • Customers can opt in to new features delivered in this update, which may be enabled or disabled by default. Use the privileges ASM_REVIEW_APPLICATIONS_OFFERINGS_PRIV and ASM_CONFIGURE_OFFERING_PRIV to review and configure offerings. (Optional Uptake of New Features (Opt In))
  • Enable Item Grade in applicable organizations using Inventory Attribute Configurations setup task to utilize inventory on hand striping attributes. (Inventory on hand striping attributes for manual transfer supply requests in Supply Chain Orchestration)
  • Set the Min-Max Replenishment Reorder Approval profile option to Approval required / Incomplete / Preapproved to route purchase requisitions through the approval workflow. (Route inventory min-max planning and PAR replenishment purchase requests through procurement approval workflow)
  • Enable electronic signature preferences and set up approval rules for Redwood UI transactions to leverage electronic records and signatures for material transactions. (Enable electronic records and electronic signatures for material transactions)
