Executive Summary

In the latest update for Supply Chain Planning (26D), significant new features have been added to both Demand Management and Supply Planning modules. The Shipment Load Planning Workspace has been introduced, allowing users to convert planning orders into actionable load recommendations, enhancing visibility into load metrics and facilitating better decision-making. Additionally, the Supply Planning Allocation Workspace enables effective allocation of scarce resources, supporting various allocation methods and providing comprehensive reporting capabilities. Customers should be aware of the opt-in requirements for the Demand Management feature and the setup needed for the Shipment Load Planning Workspace.

What's New

  • Demand Management introduces the Shipment Load Planning Workspace, which converts planning orders into load recommendations based on factors like lane and shipping method. This feature requires opting in and allows for detailed metrics visibility and report downloads. (Shipment Load Planning Workspace)
  • Supply Planning adds the Supply Planning Allocation Workspace, which automates the allocation of scarce resources and supports multiple allocation methods. This feature integrates with downstream planning actions and generates scenario reports and pivot charts automatically. (Supply Planning Allocation Workspace)
  • The Shipment Load Planning Workspace is also available in Supply Planning, providing similar functionalities as in Demand Management, including load recommendations and metrics visibility, but requires setup before use. (Shipment Load Planning Workspace)

What's Changed

None identified in this release.

Deprecations, Retirements and Replacements

None identified in this release.

Action Required

  • Opt in to the Replenishment Planning feature to utilize the Shipment Load Planning Workspace in Demand Management. (Shipment Load Planning Workspace)
  • Configure shipping equipment and units of measure, and set up lanes and multisource pickup for the Shipment Load Planning Workspace. (Shipment Load Planning Workspace; Shipment Load Planning Workspace)
  • Load setup data using FBDI and customize the Shipment Load Planning Workspace policy to meet specific operational needs. (Shipment Load Planning Workspace; Shipment Load Planning Workspace)
