SCM · Maintenance: Release digest

Covers: Maintenance 26D
Oracle updated: 1 Sep 2026 · Source: Oracle Cloud Readiness

Executive Summary

The 26D release for the Maintenance module brings significant enhancements designed to improve efficiency and user experience. Key features include the ability to associate technicians with multiple labor resources, which allows for better assignment based on skills, and the introduction of mass actions in Maintenance Supervision for managing multiple work orders. Additionally, users can now add parts from an asset's parts list directly to work orders, configure additional fields for asset details, and utilize new functionalities in Redwood pages for asset management. Customers are required to perform pre-update and post-update tasks and can opt in to new features that are delivered disabled. This release emphasizes improved operational workflows and data management capabilities.

What's New

  • Technicians can now be associated with multiple labor resources, enhancing work assignment and tracking based on skills. (Associate a technician to multiple labor resources)
  • Users can add multiple parts from an asset's parts list to work orders in Maintenance Supervision, improving efficiency. (Add parts from asset parts list to work orders in Maintenance Supervision)
  • Organizations can configure additional fields for asset details using Oracle Applications Composer and Visual Builder Studio. (Configure additional fields for asset details)
  • Maintenance supervisors can manage multiple work orders using mass actions, allowing for bulk updates and improved efficiency. (Manage multiple work orders using mass actions in Maintenance Supervision)
  • Users can access related items directly from the new Redwood Asset Details page, enhancing maintenance efficiency. (Perform additional actions in the new Redwood Asset Details page)
  • The Redwood Asset Hierarchy page now allows users to access asset details directly from the hierarchy view, improving navigation. (Perform additional actions in the new Redwood Asset Hierarchy page)
  • Business rules have been enhanced to support automatic asset number generation and validation of meter readings on the Redwood Asset Details page. (Use business rules and guided journey enhancements to configure Redwood pages)
  • Service Logistics now supports capturing quality events for returns and field service debrief, allowing users to record inspection results. (Capture quality events for returns and field service debrief)
  • The Parts Search feature now automatically includes substitutions and supersessions when searching for parts, streamlining the process. (Include substitutions and supersessions in automatic parts search)
  • Parts Search now incorporates distance into search results, optimizing part delivery based on stocking locations. (Incorporate distance into parts search)
  • Users can receive eligible purchase order lines from the Receive Parts page, supporting various item control types. (Receive purchase orders in field service Receive Part UI)
  • Service Logistics now supports credit card payments for part orders, enhancing payment flexibility for customers. (Support credit card payment method for parts orders)
  • The Parts Search program now supports supply chain transit times to destination inventory locations, improving sourcing rules. (Support destination warehouses in parts search)
  • A new user experience for setting up project-driven supply chain defaults has been introduced, simplifying configuration. (Setup project-driven supply chain defaults using a new user experience)
  • A guided process for defining plant parameters has been introduced, simplifying the definition and maintenance of parameters. (Define plant parameters using a new user experience)
  • Users can create custom SQL queries against the Read-Optimized Data Store, enhancing data extraction capabilities. (Support for user-defined queries in data extracts)

What's Changed

None identified in this release.

Deprecations, Retirements and Replacements

None identified in this release.

Action Required

  • Customers must perform pre-update and post-update tasks as required by their Cloud applications. Refer to the Oracle Fusion Cloud SCM documentation for specific steps. (Pre-Update and Post-Update Tasks)
  • Customers can opt in to new features delivered disabled in this release by using specific privileges through the New Features work area or Offerings page. (Optional Uptake of New Features (Opt In))
