SCM · SCM Analytics: Release digest

Covers: Fusion Data Intelligence 26R2
Oracle updated: 27 Jul 2026 · Source: Oracle Cloud Readiness

Executive Summary

Release 26R2 for SCM Analytics brings notable advancements in Oracle Fusion Data Intelligence, particularly enhancing the analytics modules for SCM, ERP, and HCM. Key features include the introduction of the Demand Fulfillment subject area in SCM Analytics, which supports better supply chain planning, and the renaming of Custom Data Configurations to Data Applications, allowing for more efficient data management. Additionally, HCM Analytics now features dynamic visualizations and a new workbench for analyzing employee trends. Customers should be aware of a mandatory patch to address backward compatibility issues in this release.

What's New

  • Oracle Fusion SCM Analytics introduces the Demand Fulfillment subject area, enhancing Supply Chain Planning analytics capabilities. (Oracle Fusion SCM Analytics)
  • Custom Data Configurations have been renamed to Data Applications in SCM Analytics, allowing for more frequent data refreshes and better data management. (Oracle Fusion SCM Analytics)
  • Oracle Fusion HCM Analytics adds Peer Benchmark dynamic data visualizations and a People Leader Workbench for analyzing employee trends. (Oracle Fusion HCM Analytics)
  • Oracle Fusion CX Analytics introduces a new Service Work Order Subject Area and enhances existing Eloqua subject areas for improved insights. (Oracle Fusion CX Analytics)

What's Changed

  • In Oracle Fusion ERP Analytics, the configuration of the Enterprise Calendar for Projects - Time and Labor has been updated to allow setting the Earliest Extract Date using a relative period. (Oracle Fusion ERP Analytics)

Deprecations, Retirements and Replacements

None identified in this release.

Action Required

  • Ensure to apply the mandatory patch (26.R2.P1) to resolve backward compatibility issues in the Fusion Data Intelligence instance. (26.R2)
