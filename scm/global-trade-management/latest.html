SCM · Global Trade Management: Release digest

Covers: Global Trade Management 26C
Oracle updated: 3 Aug 2026 · Source: Oracle Cloud Readiness

Executive Summary

In the 26C release of Global Trade Management, several key features have been introduced and enhanced, particularly in the areas of restricted party screening and trade compliance. New capabilities include the ability to designate parties as trusted or prohibited, enhancements to the restricted party screening workbench, and the introduction of physical inventory tracking within trade incentive programs. Additionally, the GTM Product Classification Assistant automates product classification using AI, improving compliance efficiency. Customers should note the deprecation of the 'Split Line for Penalty Reporting' action, which is replaced by the 'Apply Tariff Unstacking Rules' action, necessitating configuration updates. Overall, this release emphasizes improved operational efficiency and compliance capabilities.

What's New

  • The GTM Restricted Party Pre-processing Assistant normalizes party data before screening, enhancing accuracy and reducing mismatches. (GTM Restricted Party Pre-processing Assistant)
  • A new feature allows users to set parties as either trusted or prohibited in the party master, improving control during restricted party screening. (Set Trusted or Prohibited Party for Restricted Party Screening)
  • Physical inventory tracking within Foreign Trade Zones is now available, enhancing inventory management through trade transactions. (Physical Inventory Tracking Available in Trade Incentive Programs)
  • The GTM Product Classification Assistant automates product classification for global trade compliance using AI, proposing harmonized codes based on item data. (GTM Product Classification Assistant)
  • OAuth 2.0 authentication can now be used for BI Publisher SOAP-based report services, enhancing security by replacing embedded user credentials. (OAuth Authentication for BI Publisher SOAP Report Services)
  • A new REST API custom action allows linking a single document to multiple objects, streamlining document management processes. (REST API Custom Action to Add/Link a Document to Multiple Objects)

What's Changed

  • The Enhanced Workbench Inline Edit now always displays the External ID (XID), removing the option to switch to the Global Identifier (GID). (Inline Edit Always Shows External ID (XID))
  • The Restricted Party Screening Workbench has been enhanced with color-coded status buttons and new buttons for RPLS_OVERRIDE status values, improving user experience. (Enhancement to Restricted Party Screening Workbench)
  • Agency Code Profiles now allow inclusion or exclusion of agency codes during restricted party screening, enhancing configuration flexibility. (Include/Exclude Agency Codes in Restricted Party Screening Configuration)

Deprecations, Retirements and Replacements

  • The 'Split Line for Penalty Reporting' action is deprecated; use 'Apply Tariff Unstacking Rules' instead. (Deprecate Split Line For Penalty Reporting)
  • Basic authentication for BI Publisher SOAP web services is deprecated; transition to OAuth-based authentication is required. (Deprecate Basic Auth for BIP SOAP Web Service)
  • Global Trade Management: The existing Split Line for Penalty Reporting action is deprecated; use the Apply Tariff Unstacking Rules action instead. (Enhanced Support for Penalty Codes and Penalty Exemption Codes)

Action Required

  • Transition to the 'Apply Tariff Unstacking Rules' action by opting in to the new feature in Configuration and Administration. (Deprecate Split Line For Penalty Reporting)
  • Review and update existing BI Publisher SOAP integrations to use OAuth-based authentication instead of Basic Auth. (Deprecate Basic Auth for BIP SOAP Web Service)
