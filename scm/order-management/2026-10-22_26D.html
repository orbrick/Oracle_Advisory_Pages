SCM · Order Management: Release digest

Covers: Order Management 26D
Oracle updated: 15 Oct 2026 · Source: Oracle Cloud Readiness

Executive Summary

The 26D release of Order Management brings a host of new features aimed at enhancing supply chain orchestration, collaboration messaging, and pricing management. Key highlights include the ability to enable intra-organizational material transfers, improved handling of electronic fiscal invoices in Brazil, and the introduction of asset-based ordering. Customers are required to complete pre-update tasks and can opt into new features to fully leverage these enhancements. Additionally, the release includes various enhancements to pricing and order management parameters, ensuring a more streamlined user experience.

What's New

  • Supply Chain Orchestration now enables intra-organizational material transfers for supply requests from Self Service Procurement, improving fulfillment flexibility and inventory utilization. (Enable intra-organizational material transfers for transfer supply requests originating from Self Service Procurement)
  • Oracle Supply Chain Orchestration captures inventory on hand striping attributes for manual transfer supply requests, ensuring transfer orders reflect required inventory characteristics. (Inventory on hand striping attributes for manual transfer supply requests in Supply Chain Orchestration)
  • Collaboration Messaging allows deriving the pay site for GHX inbound invoices using B2B Account Number setup, ensuring correct routing of invoices. (Derive supplier site from invoice account numbers)
  • Organizations in Brazil can now receive additional electronic fiscal documents through Oracle Collaboration Messaging, enhancing existing messaging capabilities. (Receive Brazil electronic fiscal invoices for services and utilities)
  • The Activity Audit for Sales Orders agent introduces an audit framework to track AI-driven and user-assisted actions on sales orders, improving visibility and traceability. (AI agent activity audit for sales orders)
  • Asset-based ordering allows organizations to create orders referencing existing customer assets, supporting modifications without starting from scratch. (Asset-based ordering)
  • Users can now configure coverage and subscription items within pick-to-order models, allowing for optional warranties and maintenance agreements. (Create and process coverages and subscriptions within pick-to-order models)
  • The Sales Order Command Center now supports returns and cancellations for complex product types, leveraging AI-driven actions and intelligent recommendations. (Sales Order Command Center)
  • Pricing administrators can now price coverage and subscription components within pick-to-order model bundles, allowing for bundle-specific pricing. (Price bundles with coverages and subscriptions)
  • Users can create custom SQL queries as business object queries against the Read-Optimized Data Store, enhancing data extraction capabilities. (Support for user-defined queries in data extracts)

What's Changed

  • The redesigned parameters page for Order Management allows users to manage order management and pricing parameters with a modern interface, improving usability. (Manage order management parameters)
  • The Pricing Messages page has been redesigned to improve management while retaining existing functionality, allowing for easier search and creation of messages. (Create and manage pricing messages)
  • The Pricing Matrix Types page has been redesigned to enhance management while preserving existing functionality, improving user experience. (Create and manage pricing matrix types)

Deprecations, Retirements and Replacements

None identified in this release.

Action Required

  • Customers must perform pre-update and post-update tasks as part of their quarterly update process. Refer to the Oracle Fusion Cloud SCM documentation for specific steps. (Pre-Update and Post-Update Tasks)
  • Customers can opt in to new features delivered in this update, which may be enabled or disabled by default. Use the privileges ASM_REVIEW_APPLICATIONS_OFFERINGS_PRIV and ASM_CONFIGURE_OFFERING_PRIV to enable them. (Optional Uptake of New Features (Opt In))
