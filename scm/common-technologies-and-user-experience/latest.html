SCM · Common Technologies and User Experience: Release digest

Covers: Common Technologies and User Experience 26D
Oracle updated: 19 Oct 2026 · Source: Oracle Cloud Readiness

Executive Summary

In the 26D release for Common Technologies and User Experience, notable updates include a redesigned sign-in page for users utilizing OCI Identity and Access Management, enhancing the user experience. New features in AI Agent Studio allow for better management of AI unit budgets, integration with CI/CD processes, and the ability to create and manage Ask Oracle plugins. Additionally, contextual announcement banners can now be added to Redwood pages, and the Redwood appearance editor has been enhanced to allow brand colors as primary themes. Customers must take action regarding multifactor authentication for new environments and prepare for the deprecation of Oracle Digital Assistant skills by November 2026.

What's New

  • The Sign In page layout has been updated for environments using OCI Identity and Access Management, providing a new user interface for those users. (Changes in Oracle Fusion Cloud Applications Sign In page)
  • Users can now record issues directly on Redwood pages, which helps support teams troubleshoot and resolve problems more efficiently. (Record issues on Redwood pages)
  • AI Agent Studio introduces the ability to manage AI unit budgets and monitor consumption from a single workspace, enhancing control over AI usage. (Manage AI unit budget, consumption, and controls)
  • New integration with CI/CD processes in AI Agent Studio allows for better management of application and workflow deployments, improving deployment reliability. (Integrate AI Agent Studio applications and workflows with CI/CD)
  • The AI Agent Studio Testing and Lifecycle Automation Suite (ATLAS) now supports regression testing of workflows, enhancing quality assurance. (Test and validate AI Agent Studio workflows with ATLAS)
  • Oracle Fusion Claw is introduced, enabling users to define desired outcomes in natural language and execute actions within governance frameworks. (Use Oracle Fusion Claw to create autonomous outcomes with agentic applications)
  • New AI Guidance nodes in workflows allow for the creation and retrieval of insights, enhancing continuity across interactions. (Configure an AI guidance node in a workflow)
  • Users can create and manage Ask Oracle plugins in AI Agent Studio, extending its capabilities with specialized business expertise. (Create and manage Ask Oracle plugins)
  • Contextual announcement banners can now be enabled on Redwood pages to convey important information, improving communication with users. (Contextual announcement banner on Redwood pages)
  • The Redwood appearance editor now allows overriding accessibility checks for custom colors, enabling the use of brand colors as primary themes. (Redwood appearance editor: Override accessibility checks and use as primary color)

What's Changed

  • The Balanced category has replaced the former Premium category for selecting large language models in AI Agent Studio, although model capabilities remain unchanged. (Configure models and manage model lifecycle)

Deprecations, Retirements and Replacements

  • Certain Business Intelligence View Objects (BIVOs) are deprecated and no longer available for extraction using BI Cloud Connector. Users should review the Deprecated and New BI View Objects spreadsheets to update their BICC tasks accordingly. (Deprecated and new BI view objects in Oracle BI Cloud Connector)
  • Oracle Digital Assistant skills for Fusion Applications will be discontinued on November 21, 2026, requiring migration to AI Agent Studio as the SaaS skills will no longer be supported after this date. (IMPORTANT Actions and Considerations)

Action Required

  • Users must enroll in multifactor authentication (MFA) when signing in to Oracle Fusion Cloud Applications if they are part of new environment families created from 25D onwards. (Multifactor authentication (MFA))
