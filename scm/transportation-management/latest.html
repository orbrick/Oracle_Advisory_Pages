SCM · Transportation Management: Release digest

Covers: Transportation Management 26C
Oracle updated: 3 Aug 2026 · Source: Oracle Cloud Readiness

Executive Summary

The 26C release of Transportation Management brings a host of new features and enhancements aimed at improving user experience and operational efficiency. Key highlights include the introduction of AI capabilities such as the Dock Scheduling Assistant and Shipment Change Assistant, which leverage natural language processing to simplify dock scheduling and shipment management. The Redwood user interface has been expanded with additional features, enhancing usability across the platform. Customers should note the deprecation of Basic Auth for BI Publisher SOAP Web Services, requiring a transition to OAuth-based authentication for improved security. Overall, this release emphasizes automation, usability, and integration capabilities across the Transportation Management module.

What's New

  • AI Agent Studio now includes thirty pre-seeded OTM/GTM business objects, facilitating easier AI agent development. (AI Agent Studio - Seeded Business Objects)
  • A new slash command feature allows users to quickly insert reusable AI prompt templates in the chat input box, enhancing efficiency. (Slash Command for Prompt Selection)
  • The Redwood user interface has been extended to include additional UIs and features, improving usability and efficiency. (Try the New Redwood Experience)
  • The Enhanced Workbench now always displays the External ID (XID) in Inline Edit, simplifying the editing process. (Inline Edit Always Shows External ID (XID))
  • A new logic configuration parameter allows updates in Workbench detail tables to be processed as a single transaction, reducing duplicate notifications. (Single Transaction Option for Workbench Inline Editing and Mass Updates)
  • The Honor Update Flag For REST RefNum Updates feature aligns REST services with XML APIs regarding how the Update Flag is handled for reference numbers. (Honor Update Flag For REST RefNum Updates)
  • The Enable Req Att Validation For REST API feature validates JSON payloads for POST requests to ensure required attributes are included for creating objects. (Enable Req Att Validation For REST API)
  • A new REST API Custom Action allows linking a single document to multiple business objects in one action, streamlining document management. (REST API Custom Action to Add/Link a Document to Multiple Objects)
  • The Multi-Day Calendar Override feature allows users to define both start and end dates for calendar override entries, applicable across operational areas. (Multi-Day Calendar Overrides)
  • New Shipment Group tender agent actions have been added to automate the Shipment Group tender workflow, enhancing operational efficiency. (Automation Agent Actions - Shipment Group Tender)

What's Changed

  • The Order Routing Rule functionality now includes Itinerary ID and Routing Constraint ID in the Order Routing Rule Detail screen, improving routing decisions. (Preferred Routing - Order Routing Rule)
  • The Rate Shopping feature now provides visibility to the Rate Service in external rate shopping setups, ensuring recalculated shipment costs reflect the originally selected service provider. (Rate Shopping - Rate Service Visibility - Change Service Provider)

Deprecations, Retirements and Replacements

  • Basic Auth for BI Publisher SOAP Web Service is deprecated, requiring the use of OAuth-based authentication instead. (Deprecate Basic Auth for BIP SOAP Web Service)
  • Transportation Management: The Logic Configuration Parameter SHOW XID IN INLINE EDIT is no longer considered and will be removed in a future release. (Inline Edit Always Shows External ID (XID))
  • Transportation Management: This feature replaces the property glog.business.shipmentactual.syncWithOrderOnCountIncrease. (SMD Sync With Order On SSU Count Increase)

Action Required

  • Users must opt in to the Use Improved Split Order Movement Action feature through the Optional Feature UI to take advantage of the improved logic. (Use Improved Split Order Movement Action)
  • Users must opt in to the Suppress Error When No REST RIQ Results Found feature through the Optional Feature UI to utilize it. (Suppress Error When No REST RIQ Results Found)
  • Users must opt in to the Fetch All Shipment Tracking Events feature through the Optional Feature UI to utilize it. (Fetch All Shipment Tracking Events)
  • Users must opt in to the SMD Sync With Order On SSU Count Increase feature through the Optional Feature UI to utilize it. (SMD Sync With Order On SSU Count Increase)
  • Users must enable the Optional Feature 'Use 3D Load Config for Ground Schedule and Consol' to utilize 3D load configuration for Ground Schedule and consol shipments. (Use 3D Load Config for Ground Schedule and Consol)
