Executive Summary

In the latest update for Manufacturing (release 26D), significant enhancements have been made to the parent lot capabilities within Discrete Manufacturing. These improvements focus on better tracking and validation during production transactions, including required validations during product completion and enhanced search functionalities for lots. Customers will need to enable parent lot management and adjust settings in Product Information Management to leverage these new features. No deprecations were noted in this release.

What's New

  • Discrete Manufacturing enhances parent lot capabilities, requiring validation during product completion and allowing searches by parent lot number. This is. (Capture parent lot and lot information for production transactions)
  • The system now automatically displays associated parent lots when selecting existing lots, improving user experience during transactions. This is. (Capture parent lot and lot information for production transactions)
  • Changes to File-Based Data Import (FBDI) and REST APIs now include parent lot information, facilitating better integration and data management. This is. (Capture parent lot and lot information for production transactions)
