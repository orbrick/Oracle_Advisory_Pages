SCM · Procurement: Release digest

Covers: Procurement 26D, Self Service Procurement 26D
Oracle updated: 2 Oct 2026 · Source: Oracle Cloud Readiness

Executive Summary

Release 26D for Procurement and Self Service Procurement brings a host of new features aimed at enhancing procurement efficiency and flexibility. Key highlights include support for intra-organizational material transfers, improved inventory management with grade attributes, and enhanced collaboration through Microsoft Teams integration. Additionally, the Procurement Spend Command Center has been introduced to help identify off-contract spending. Clients should note that some features require opting in to activate, and they should review the new features work area to ensure they benefit from the latest capabilities.

What's New

  • Procurement introduces support for intra-organizational material transfers, allowing users to identify optimal supply sources across inventory organizations, enhancing fulfillment flexibility. (Enable intra-organizational material transfers for transfer supply requests originating from Self Service Procurement; Enable intra-organizational material transfers for transfer supply requests originating from Self Service Procurement)
  • New inventory on hand striping attributes for manual transfer supply requests ensure transfer orders reflect required inventory characteristics, improving fulfillment precision. (Inventory on hand striping attributes for manual transfer supply requests in Supply Chain Orchestration; Inventory on hand striping attributes for manual transfer supply requests in Supply Chain Orchestration)
  • The Procurement Spend Command Center helps users identify maverick spend and agreement leakage, providing insights into procurement activities. (Procurement Spend Command Center)
  • Collaboration Messaging now allows deriving supplier sites from invoice account numbers, ensuring invoices are routed correctly. (Derive supplier site from invoice account numbers)
  • New REST resources have been introduced to simplify integration with external systems, enhancing procurement interoperability. (Integrate and extend procurement using REST resources; Integrate and extend procurement using REST resources)
  • The Intake Request Creation Assistant has been enhanced with features like automatic UOM validation and AI-generated summaries, improving the request process. (Intake Request Creation Assistant - Create and review with enhanced features)
  • Catalog administrators can now manage catalogs, smart forms, and information templates through a new user experience, streamlining catalog management tasks. (Manage catalog administration tasks using a new user experience; Manage catalogs; Manage information templates)
  • Users can now search for suppliers using tax identifiers, enhancing supplier management capabilities. (Search for suppliers using tax identifiers)

What's Changed

  • Purchase requisitions from min-max planning can now be automatically routed through the procurement approval workflow, streamlining the replenishment process. (Route inventory min-max planning and PAR replenishment purchase requests through procurement approval workflow; Route inventory min-max planning and PAR replenishment purchase requests through procurement approval workflow)
  • Table column personalizations are now retained across sessions for various Procurement pages, improving user experience. (Retain column personalizations for table layouts on Purchasing pages; Retain column personalizations for table layouts on Supplier Model pages; Retain column personalizations for table layouts on Sourcing pages)
  • The requisition approval process now includes more detailed error messages, enhancing user guidance during approvals. (Display detailed error messages in requisition approvals)

Deprecations, Retirements and Replacements

  • The original Redwood supplier search feature will be removed in update 27B, replaced by a new feature that allows searching for suppliers using tax identifiers. (IMPORTANT Actions and Considerations)
  • Procurement: Classic View Invoices, View Payments, Create Invoice, and Create Invoice without PO pages are no longer available after enabling Redwood. (Redwood Supplier Portal Invoice Submission and Status Tracking)

Action Required

  • Clients must review and opt in to new features delivered in this release to activate them. (Optional Uptake of New Features (Opt In); Optional Uptake of New Features (Opt In))
  • Enable the profile option for the Redwood Supplier Portal Home Page to access the new user experience for invoices and payments. (Redwood Supplier Portal Invoice Submission and Status Tracking)
  • Set up Microsoft Teams integration to facilitate collaboration on procurement documents. (Collaborate on procurement documents and intake requests using Microsoft Teams)
