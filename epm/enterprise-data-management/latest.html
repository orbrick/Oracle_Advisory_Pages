EPM · Enterprise Data Management: Release digest

Covers: Enterprise Data Management 26.11
Oracle updated: 29 Oct 2026 · Source: Oracle Cloud Readiness

Executive Summary

In the 26.11 release of Enterprise Data Management, new AI Skills have been introduced to streamline various administrative tasks, allowing users to perform actions through natural language queries. Additionally, new REST APIs enhance the functionality for Activity Reports and Access Logs, while existing APIs have been improved to support non-ASCII filenames and a number-of-days option for report generation. Customers should note that support for user names prefixed with the Cloud Account name in EPM Automate has been removed, necessitating adjustments for security compliance. Furthermore, generative AI features will require an upgrade to Cloud EPM 26.08 or later by January 2027, and EPM Automate clients earlier than 26.09 will not be compatible with future environments.

What's New

  • New Cloud EPM AI Skills have been introduced for various administrative tasks, allowing natural language queries and actions across 11 functional areas. (New Skills for Core Infrastructure Management Including Security, Audit, Migration, Activity Reporting, Essbase Diagnostics, and Concurrent Testing)
  • New REST APIs have been introduced to list Activity Reports and Access Logs, allowing retrieval of JSON content and CSV downloads with filtering options. (New REST APIs for Activity Reports and Access Logs)
  • New sample scripts for Linux and Windows PowerShell are available to automate the cloning of environments using the latest environment backup. (New Script to Clone Environments Using the Latest Environment Backup)

What's Changed

  • Audit and Login Report REST APIs and EPM Automate commands now support a number-of-days option for report generation, simplifying automated reporting. (Support of Number of Days Option in Audit and Login Report REST APIs and EPM Automate Commands)
  • Download REST APIs now preserve non-ASCII filenames, allowing users to retain original filenames when downloading files. (Support for Non-ASCII Filenames in Download REST APIs)
  • Changes to the update cadence policy for non-mainline Cloud EPM environments now limit one-off patches and skip updates to a maximum of six months with Oracle approval. (Changes to the Cloud EPM Update Cadence Policy for Environments Not on the Mainline)

Deprecations, Retirements and Replacements

  • Support for user names prefixed with the Cloud Account name in EPM Automate login commands and REST APIs has been removed, enhancing security. (Removal of Support for User Names Prefixed with the Cloud Account Name for EPM Automate Login Command and REST APIs)
  • Support for JDK 17 in EPM Automate on Linux and UNIX will be deprecated in January 2027, requiring an upgrade to JDK 21. (IMPORTANT Actions and Considerations)

Action Required

  • Upgrade EPM Automate to version 26.09 or later to ensure compatibility with future environments. (IMPORTANT Actions and Considerations)
  • Run the EPM Automate encrypt command to generate a new.epw file as part of the upgrade process. (IMPORTANT Actions and Considerations)
