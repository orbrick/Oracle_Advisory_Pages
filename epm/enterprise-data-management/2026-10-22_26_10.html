EPM · Enterprise Data Management: Release digest

Covers: Enterprise Data Management 26.10
Oracle updated: 23 Sep 2026 · Source: Oracle Cloud Readiness

Executive Summary

The 26.10 release of Enterprise Data Management brings several important updates, including a new chapter on AI in business process guides and enhanced security features for user access control. The introduction of the listUsers command in EPM Automate allows for better user management, while support for JDK 21 is now required for EPM Automate on Linux/Unix systems, with JDK 17 being deprecated in January 2027. Additionally, generative AI features will necessitate an upgrade to Cloud EPM 26.08 or later by January 2027, and EPM Automate clients earlier than version 26.09 will not function with environments 26.12 and later, requiring timely upgrades.

What's New

  • Enterprise Data Management adds a new chapter titled 'Working with AI' to business process guides, detailing AI features and usage documentation. (New "Working with AI" Chapter)
  • A new listUsers command and corresponding REST API are introduced in EPM Automate, allowing for the creation of a JSON report listing users and their roles. (New listUsers EPM Automate Command and REST API)
  • The Export to CSV option in Access Control now supports exporting all group types, including EPM, IDCS, and PREDEFINED groups, enhancing security reviews. (Support of All Group Types in Exported Group Listing in Access Control)

What's Changed

  • The copyToSFTP and copyFromSFTP commands in EPM Automate now support an uploaded private key file when invoked from Groovy scripts, improving security. (Support for Uploaded Private Key in copyToSFTP and copyFromSFTP Commands Invoked From Groovy Scripts)

Deprecations, Retirements and Replacements

  • Support for JDK 17 will be deprecated in January 2027, requiring an upgrade to JDK 21 for EPM Automate on Linux/Unix systems. (Java 21 support for EPM Automate on Linux/Unix)
  • Support for user names prefixed with the Cloud Account name will be removed in November 2027. (IMPORTANT Actions and Considerations)

Action Required

  • Upgrade EPM Automate to version 26.09 or later to ensure compatibility with environments 26.12 and later. (IMPORTANT Actions and Considerations)
  • Run the EPM Automate encrypt command to generate a new.epw file after upgrading. (IMPORTANT Actions and Considerations)
  • Upgrade JDK to version 21 on Linux/Unix systems to comply with the new requirements for EPM Automate. (Java 21 support for EPM Automate on Linux/Unix)
