EPM · Enterprise Performance Management: Release digest

Covers: Enterprise Performance Management 26.10
Oracle updated: 12 Oct 2026 · Source: Oracle Cloud Readiness

Executive Summary

The 26.10 release of Enterprise Performance Management brings a host of new features and enhancements across various modules, focusing on AI capabilities and improved user experiences. Key highlights include the Enhanced PCM Agent for performance analysis, the Consolidation Process Assistant for data integrations, and a redesigned Jobs console for better job management. Additionally, the release introduces new REST APIs and enhancements to existing functionalities, such as improved security for EPM Cloud connections. Clients should be aware of the deprecation of JDK 17 support in EPM Automate, which will require an upgrade to JDK 21 by January 2027, and other important actions to ensure compliance with upcoming changes.

What's New

  • The Enhanced PCM Agent now includes performance analysis capabilities, allowing users to analyze completed calculation jobs and receive optimization recommendations. (EPM Spotlight Features)
  • A new Consolidation Process Assistant enables users to execute data integrations and consolidations through natural language interactions, enhancing productivity. (EPM Assistants: Consolidation Process Assistant)
  • The Reporting Agent now assists in investigating data patterns by generating a ranked analysis grid that identifies contributors to a value. (Reporting Agent Causal Analysis)
  • EPM Cloud can now access Oracle Fusion Applications REST APIs using OAuth 2.0, enhancing security for server-to-server integrations. (Configure EPM Cloud to Access Oracle Fusion Applications REST APIs with OAuth 2.0)
  • A new 'Working with AI' chapter has been added to business process guides, detailing available AI features and usage documentation. (New "Working with AI" Chapter)
  • The Transactions tab now displays the total transaction amount alongside the number of transactions based on current search criteria, improving productivity during audits. (Display of Transaction Sum in the Transactions Tab of Transaction Matching)
  • The new Balance Loads card streamlines the balance load process, featuring tabs for Balance Loads, Mapping Exceptions, and Profile Creation Rules. (Manage Balance Loads Using the Balance Loads Card)
  • The Predict Predicted Attribute REST API now supports predicting multiple target attributes in a single request, improving performance for multi-attribute workflows. (Predict Multiple Attributes in a Single REST API Request)
  • A new REST API for retrieving translation diagnostic information has been introduced, enabling automated investigation of translation issues. (Diagnosis of Translation Issues Using a REST API)
  • The application Home page has been enhanced with Redwood styling, improving accessibility and navigation for users across various modules. (Enhanced Home Page and Global Header Experience; Enhanced Home Page and Global Header Experience; Enhanced Home Page and Global Header Experience)

What's Changed

  • The Export to CSV option in Access Control now supports exporting all group types, including EPM, IDCS, and PREDEFINED groups. (Support of All Group Types in Exported Group Listing in Access Control)
  • The ownership copying process now allows users to copy only the changed ownership data from the last period of a year to the first period of the next year, improving efficiency. (Copy Ownership Now Allows Copying Only Changed Ownership Data)
  • The conditional Replace Text option now supports text functions, enabling dynamic text display based on specified conditions without altering the underlying grid data. (Text Functions in Conditional Replace Text)
  • Insertion points in the consolidation sequence now allow the use of attribute functions in on-demand rules, enabling more flexible calculation logic. (Insertion Point Rules Opend up to Allow Attribute Dimension Functions)

Deprecations, Retirements and Replacements

  • Support for JDK 17 in EPM Automate on Linux/Unix will be deprecated in the January 2027 update, requiring an upgrade to JDK 21. (Java 21 support for EPM Automate on Linux/Unix)
  • The original PCM Agent and PCM Agent Performance Assistant will no longer be available starting in the November update (26.11). (PCM Agent Calculation Performance Analysis Capabilities)
  • Generative AI features require Cloud EPM 26.08 or later by January 2027, and support for user names prefixed with the Cloud Account name will be removed in November 2026. (IMPORTANT Actions and Considerations)

Action Required

  • Upgrade EPM Automate to version 26.09 or later and run the EPM Automate encrypt command to generate a new.epw file. (IMPORTANT Actions and Considerations)
  • Review existing connection definitions for IP addresses and update queries for TM_AUDIT_TRAIL table as support for IP addresses in Connection URLs will be removed in a future update. (IMPORTANT Actions and Considerations)
  • Service Administrators should configure automatic purging of balance load information after a specified number of days to maintain application performance. (Ability to Automatically Purge Balance Load Information)
  • Enable the new Consolidation Setting called 'Data Retrieval Diagnosis' for the new EPM Assistants to function properly. (EPM Assistants: Consolidation Process Assistant; EPM Assistants: Consolidation Journals Assistant)
