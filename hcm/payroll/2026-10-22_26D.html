HCM · Payroll: Release digest

Covers: Payroll 26D
Oracle updated: 29 Sep 2026 · Source: Oracle Cloud Readiness

Executive Summary

Release 26D introduces key enhancements across the Payroll modules, particularly for the United States, Ireland, Canada, and the United Kingdom. Noteworthy updates include automation for SECURE 2.0 Act compliance, a new Tax Calculation Statement page for detailed tax insights, and enhancements to the Payroll Run Analyst AI Agent for improved query handling. Additionally, organizations must take action to reimplement upgraded time elements before the next release to ensure continued functionality. Other enhancements include Redwood experiences for various payroll processes, improving user experience and operational efficiency.

What's New

  • Payroll introduces a new Tax Calculation Statement tab on the Person Results page, providing detailed tax calculation information for Federal Income Tax. (Tax Calculation Statement Page: Federal Income Tax)
  • The Payroll Run Analyst AI Agent now supports the Tax Calculation Statement, enabling natural-language queries about payroll tax deductions. (Payroll Run Analyst AI Agent Enhanced to Support the Tax Calculation Statement (Federal Income Tax))
  • A Redwood experience for managing organization calculation cards has been added, allowing users to create Legal Entity and Legal Reporting Unit calculation cards. (Redwood Experience for Organization Calculation Cards)
  • The Redwood experience for multiple balance adjustments has been redesigned, simplifying the adjustment process for tax balances. (Redwood Experience for Multiple Balance Adjustments)
  • Payroll for Ireland now includes a Periodic Foreign Tax Credit feature, enhancing compliance for employees eligible for foreign tax credit relief. (Periodic Foreign Tax Credit)
  • The Payroll Activity Center has been introduced for various regions, allowing users to compare balance values for multiple pay periods side by side, improving review efficiency. (Payroll Activity Center; Payroll Activity Center; Payroll Activity Center)
  • Payroll for Canada now features a new flow for annual indexing of personal tax credit overrides, supporting cumulative adjustments across tax years. (Tax Credit and Total Claim Amount Indexing)
  • The Payroll Balance Migration Workflow Agent has been introduced for France, assisting in preparing payroll balance initialization files during migrations. (Payroll Balance Migration Workflow Agent)

What's Changed

  • The gratuity calculation for fixed-term contract employees in Saudi Arabia has been updated to ensure compliance with local legislation regarding termination pay. (Saudi Gratuity Calculation Update)
  • UK SSP processing will now utilize the published schedule in effect before a sickness absence to determine qualifying days, enhancing consistency in payment outcomes. (Use Published Schedules to Determine UK Statutory Sick Pay Qualifying Days)

Deprecations, Retirements and Replacements

  • The feature for time elements upgraded to calculation cards will be removed in release 27D, replaced by the Create Time Card Calculation Component process. (Important Actions and Considerations for Payroll)

Action Required

  • Organizations must reimplement upgraded time elements using the Create Time Card Calculation Component process to avoid disruptions in functionality. (Retire Upgraded Time Elements)
  • For the Payroll Run Analyst AI Agent, configure the Agent Guided Journey to extend the Person Results page for optimal use. (Payroll Run Analyst AI Agent Enhanced to Support the Tax Calculation Statement (Federal Income Tax))
  • Enable the required profile options for the Redwood page for multiple balance adjustments to utilize the new features effectively. (Redwood Experience for Multiple Balance Adjustments)
  • Set the appropriate profile options to enable the Payroll Activity Center for various regions to enhance payroll management. (Payroll Activity Center; Payroll Activity Center; Payroll Activity Center)
