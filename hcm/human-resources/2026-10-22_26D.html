HCM · Human Resources: Release digest

Covers: Benefits 26D, HCM Common 26D, Help Desk 26D, Human Resources 26D, Work Life 26C, Workforce Modeling & Prediction 26D
Oracle updated: 5 Oct 2026 · Source: Oracle Cloud Readiness

Executive Summary

The 26D release for Human Resources brings a host of new features and enhancements aimed at improving user experience and operational efficiency. The Benefits module introduces the Life Event Simulation Analyst, allowing users to simulate life events without making permanent changes, and the Benefits Administration Command Center, which provides a centralized workspace for managing benefits issues. HCM Common sees enhancements like the AI Agent for Data Load Advisor, enabling natural language requests for data loading processes. The Help Desk module also benefits from a transition to the Redwood experience, enhancing usability across various administrative tasks. Additionally, clients should be aware of the upcoming deprecation of legacy navigation in the next release, necessitating migration to the Redwood interface.

What's New

  • Benefits introduces the Life Event Simulation Analyst, allowing users to simulate life events without permanent changes, enhancing benefits management. (Life Event Simulation Analyst)
  • The Benefits Administration Command Center provides a unified workspace for managing benefits issues, featuring AI-generated summaries and insights. (Benefits Administration Command Center)
  • HCM Common now includes an AI Agent for Data Load Advisor, enabling users to initiate data loading processes using natural language. (AI Agent: Data Load Advisor - Initiate HDL)
  • Help Desk transitions to a Redwood interface, enhancing user experience for administrative tasks. (Use Redwood for administration and configuration tasks)
  • The Redwood experience is now enabled by default for various Employment pages, improving access and usability. (Redwood Enabled by Default for Employment Pages in Update 26D)
  • The Workforce Orchestration Command Center is introduced to help leaders identify workforce conditions needing attention. (Workforce Orchestration Command Center)

What's Changed

  • The Actions list in Redwood Change Assignment now allows actions like Suspend Assignment and End Probation to be available even when their conditions are not met, improving user experience. (Enhanced Action List in Redwood Change Assignment)
  • Redwood person pages are now enabled by default, replacing responsive pages, enhancing user experience. (Redwood Enabled by Default for Person Pages)

Deprecations, Retirements and Replacements

  • The Process Automation task type is deprecated and will not be available after October 31, 2026, affecting journey setup pages. (Process Automation Task Type No Longer Available in Journeys Setup)
  • The Personal Information Assistant and Person Legislative Information supervisor agent templates are deprecated; users are encouraged to transition to the Person Data Assistant. (Personal Information Assistant and Person Legislative Information Agents Are Replaced by Person Data Assistant Agent)
  • Human Resources: Effective from release 27B, legacy Person Management and Person Spotlight navigation will be disabled by default, including related tiles and quick actions. Users can still access these pages by manually setting the relevant profile option to No after the update. (Upcoming Changes to Legacy Person Navigation in Update 27B)
  • Human Resources: The existing Supervisor Agent template will no longer be supported. (Manage Journeys with AI Assistance)
  • Human Resources: The Representative Agent, a supervisor agent type, is deprecated in this release. Users are encouraged to transition to the Representative Assistant, which offers more capabilities. (Deprecating the Representative Agent (Supervisor Agent Type))

Action Required

  • Organizations must migrate to the Redwood Help Desk experience before the 27B update, as the Classic Help Desk will be unavailable after that release. (UPDATED DATE: Migrate from Classic HR Help Desk to Redwood PRIOR to 27B)
  • A baseline extraction must be performed for payroll interfaces generated from the Global Payroll Interface template after applying this update. (Perform a Baseline Extraction of Payroll Interfaces Generated from Global Payroll Interface Template)
  • A baseline extraction must be performed for the Payroll Interface for ADP Global Payroll V2 after applying this update. (Perform a Baseline Extraction of Payroll Interface for ADP Global Payroll V2)
  • A baseline extraction must be performed for the Payroll Interface for ADP Workforce Now after applying this update. (Perform a Baseline Extraction of Payroll Interface for ADP Workforce Now)
  • A baseline extraction must be performed for the Payroll Interface for ADP Workforce Now V2 after applying this update. (Perform a Baseline Extraction of Payroll Interface for ADP Workforce Now V2)
  • A baseline extraction must be performed for the Payroll Interface for ADP Global Payroll after applying this update. (Perform a Baseline Extraction of Payroll Interface for ADP Global Payroll)
