HCM · Human Resources: Update digest (additions since the last digest)

Covers: Benefits 26D, Human Resources 26D, Workforce Modeling & Prediction 26D
Oracle updated: 30 Oct 2026 · Source: Oracle Cloud Readiness

Executive Summary

In the latest 26D release, the Human Resources category sees substantial enhancements aimed at improving user experience and operational efficiency. The Benefits module now features a streamlined Enrollment Summary, while the Human Resources module introduces AI capabilities for document management and onboarding tasks. Additionally, the Workforce Modeling & Prediction module presents the Workforce Orchestration Command Center, enabling leaders to monitor workforce stability and take informed actions. Customers should note the upcoming automatic upgrade to the Connections Waterfall View in release 27A, which requires review of existing configurations.

What's New

  • Benefits introduces conditional display of enrollment summary regions, hiding optional sections without applicable records, enhancing clarity for administrators. (Conditional Display of Enrollment Summary Regions Based on Enrollment Data)
  • The Document Records Management Assistant can now generate document records from uploaded attachments, streamlining the creation process with AI validation. (Generate Document Records from Uploaded Attachments with AI Assistance)
  • The Onboard AI Assistant now recommends relevant learning content and onboarding tasks, improving the onboarding experience for new hires. (Journey Task Suggestions from Learn and Task Library in Onboard AI Assistant)
  • The HCM Professional Concierge Workflow Agent assists HR specialists in retrieving relevant HCM data through natural language queries, enhancing operational efficiency. (HCM Professional Concierge Workflow Agent)
  • The Workforce Orchestration Command Center helps leaders assess workforce conditions and suggests priority actions based on workforce stability indicators. (Workforce Orchestration Command Center)

What's Changed

  • The Actions list in Redwood Change Assignment now allows selection of previously restricted actions regardless of assignment status, improving user experience. (Enhanced Action List in Redwood Change Assignment)
  • The Assignment Change Assistant now supports a broader range of scenarios and allows for more flexible modifications of employment attributes. (Enhancements to Assignment Change Assistant with AI Assistance)
  • Access to work patterns has been separated for line managers, enhancing control over work pattern security and management. (Separate Line Manager Access to Work Patterns)
  • The Person Data Assistant AI Agent now supports additional demographic data management capabilities, allowing for more comprehensive data handling. (Person Data Assistant Workflow Agent Enhancements)

Deprecations, Retirements and Replacements

  • The existing Supervisor Agent template will no longer be supported with the enhancement of the Journeys Assistant, which converts it to a workflow. (Manage Journeys with AI Assistance)
  • In release 27A, users of the Connections horizontal view will be automatically upgraded to the waterfall view, requiring review of existing configurations. (Announcement - Automatic Upgrade to Connections Waterfall View in 27A)

Action Required

  • Create your own agent using the preconfigured workflow to utilize the enhanced Document Records Management Assistant and Assignment Change Assistant features. (Generate Document Records from Uploaded Attachments with AI Assistance; Enhancements to Assignment Change Assistant with AI Assistance)
  • Review and configure properties for the upcoming automatic upgrade to the Connections Waterfall View in release 27A to ensure compatibility. (Announcement - Automatic Upgrade to Connections Waterfall View in 27A)
  • Provide required access for line managers to manage work patterns effectively before using the new feature. (Separate Line Manager Access to Work Patterns)
