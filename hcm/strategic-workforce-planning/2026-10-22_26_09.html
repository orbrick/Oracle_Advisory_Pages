HCM · Strategic Workforce Planning: Release digest

Covers: Enterprise Performance Management 26.09
Oracle updated: 24 Sep 2026 · Source: Oracle Cloud Readiness

Executive Summary

The 26.09 release of the Enterprise Performance Management module brings a host of new AI-driven features aimed at improving financial workflows and data management. Key highlights include the introduction of the Consolidation Assistant and Tax Journal Assistant, which leverage generative AI to enhance financial consolidation and tax reporting processes. Furthermore, predefined dashboards in Strategic Workforce Planning have been automatically upgraded to Dashboard 2.0, providing users with a more modern interface and improved functionality. Customers should note the importance of updating existing Cloud EPM connections to specify an Access Token URI for OAuth 2.0 authentication to ensure secure access.

What's New

  • The Consolidation Assistant helps diagnose system issues and recommends resolutions using generative AI, enhancing the financial consolidation process. (Consolidation Assistant)
  • The Tax Journal Assistant streamlines the creation of consolidation journals from TAR Journal Posting data, automating data extraction and mapping. (EPM Assistants: Tax Journal Assistant for Users)
  • Generative AI functionality is now available in OC2 and OC3 realms, allowing customers to utilize AI capabilities across various Cloud EPM applications. (Generative AI Support Available in OC2 and OC3 Realm)
  • Predefined dashboards in Strategic Workforce Planning are automatically upgraded to Dashboard 2.0, enhancing user experience with modern features. (Predefined Dashboards in Modules, Sales Planning and Strategic Workforce Planning Automatically Upgraded to Dashboard 2.0)
  • New AI chapters on adoption and industry use cases have been added to the Oracle Cloud EPM Center of Excellence Guide, assisting organizations in building an AI-enabled EPM roadmap. (New AI Adoption and Industry Use Cases Chapters in the Oracle Cloud EPM Center of Excellence Guide)
  • The new runApplicationDiagnostics EPM Automate command allows users to create an Application Diagnostics report to validate compliance with best practices. (New runApplicationDiagnostics EPM Automate Command)
  • New properties for handling Pillar Two tax allocations are now available in Tax Reporting applications, enhancing tax management capabilities. (Additional Pillar Two Tax Allocation Properties for Tax Reporting Applications)
  • The Change Management Assistant has been enhanced with improved search capabilities and a new welcome message, facilitating easier change management. (Change Management Assistant Enhancements)
  • The ability to attach multiple files simultaneously has been added to Task Manager and other modules, streamlining file management workflows. (Ability to Attach Multiple Files Simultaneously)
  • New audit data retention periods for role and group assignment reports have been updated, allowing for longer retention periods of up to 120 days. (Audit Data Availability Through EPM Automate and REST APIs)

What's Changed

  • The resubmission process for enriched requests now allows users to submit requests even if they lack direct access to changes made during the enrichment stage, simplifying the workflow. (Relaxed Permission Check During Resubmit of Enriched Request)
  • The First Name field for creating and updating users in Cloud EPM is now optional, improving user administration flexibility. (First Name Is Optional for EPM Users)
  • Environments can now remain on a one-off patch for a maximum of six months, ensuring compliance with security standards while managing updates effectively. (Environments to Remain on One-off Patch or Manual Skip Update for a Maximum of Six Months)

Deprecations, Retirements and Replacements

  • The original PCM Agent will be deprecated starting with the October update (26.10). Users should transition to the Enhanced PCM Agent for continued support. (The Enhanced PCM Agent Now Supports Trace)

Action Required

  • Update existing Cloud EPM connections to specify an Access Token URI for OAuth 2.0 authentication to ensure secure access. (Access Token URI for OAuth 2.0 Cloud EPM Connections)
  • Enable Generative AI features in Application Settings to utilize the new AI capabilities in the Consolidation Assistant and Tax Journal Assistant. (Consolidation Assistant; EPM Assistants: Tax Journal Assistant for Users)
  • Enable the Include Management Hierarchy parameter in the ownership approval policy inspector to utilize the new management hierarchy feature. (Include Management Hierarchy for Ownership Approval Policies)
  • Define controlling properties and allowed values for node contexts to utilize the new contextual properties feature in Enterprise Data Management. (Contextual Properties for Nodes in Viewpoints)
  • Edit the Default Property Group parameter in the viewpoint inspector to configure default property groups for viewpoints. (Default Property Groups for Viewpoints)
  • Register integrations in Enterprise Data Management and assign the Integrations - Manage role to users to execute and monitor Oracle Integration Cloud processes. (Execute and Monitor Oracle Integration Cloud Processes)
