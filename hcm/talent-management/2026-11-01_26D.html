HCM · Talent Management: Release digest

Covers: Learning and Development 26D, Oracle Me Employee Experience 26D, Recruiting 26D, Talent Management 26D
Oracle updated: 30 Oct 2026 · Source: Oracle Cloud Readiness

Executive Summary

The 26D release introduces significant enhancements across several modules in Talent Management, including Learning and Development, Oracle Me Employee Experience, Recruiting, and Talent Management. Notable new features include the Redwood Community Management for Learning, which allows users to create and manage communities, and the Learning and Development Analyst, enabling natural-language queries for learning data insights. In Oracle Me, new functionalities for managing employee events and feedback collection have been added, while Recruiting sees improvements in candidate communication and notification management. Additionally, Talent Management introduces enhancements to goal management and performance evaluations, with a focus on AI-driven capabilities. Customers should note the deprecation of responsive pages for feedback functionalities, now replaced by Redwood-enabled pages.

What's New

  • Learning and Development introduces Redwood Community Management, allowing users to create and manage official communities, enhancing community engagement and learning opportunities. (Redwood Community Management)
  • The Learning and Development Analyst feature enables users to explore learning data through natural-language questions, providing insights into completion status and overdue assignments. (Learning and Development Analyst)
  • Oracle Me now supports creating campaigns that collect feedback using HCM questionnaires, facilitating structured feedback collection from employees. (Use Questionnaires in Oracle Communicate Campaigns)
  • Recruiting enhances candidate communication by allowing WhatsApp messaging through the Career Coach, improving engagement and support for candidates. (Career Coach Enhancements: Use Text Assistant for WhatsApp Messages)
  • Talent Management adds support for goal-level approvals in the Employee Goals Assistant, streamlining the goal-setting process without locking the entire plan. (Support Goal Level Approvals in the Employee Goals Assistant Agent)
  • The Manager Coaching Workspace provides managers with insights derived from HCM Talent data, helping prioritize coaching conversations based on team-level themes. (Identify Coaching Insights for your Team Using Manager Coaching Workspace)

What's Changed

  • The Anytime (Give) Feedback and Requested Feedback pages are now enabled for Redwood by default, enhancing user experience and performance. (Redwood Enabled by Default for Anytime (Give) Feedback and Requested Feedback Pages)

Deprecations, Retirements and Replacements

  • Responsive pages for Anytime Feedback and Requested Feedback are deprecated and will no longer be supported. (Redwood Enabled by Default for Anytime (Give) Feedback and Requested Feedback Pages)

Action Required

  • Set the site-level profile value to Y for ORA_WLF_COMMUNITIES_REDOOD_ENABLED to enable Redwood Community Management. (Redwood Community Management)
  • Enable the Goal Level Approval Enabled profile option (ORA_HRG_PERF_GOAL_LVL_APPROVL) to utilize goal-level approvals in the Employee Goals Assistant. (Support Goal Level Approvals in the Employee Goals Assistant Agent)
  • Run the Aggregate Oracle Touchpoints Data scheduled process daily to utilize the new Manager Coaching Workspace features. (Identify Coaching Insights for your Team Using Manager Coaching Workspace)
