HCM · Talent Management: Release digest

Covers: Compensation 26D, Dynamic Skills 26D, Learning and Development 26D, Opportunity Marketplace 26D, Oracle Me Employee Experience 26D, Recruiting 26D, Talent Management 26D, Taleo Business (TBE) 25C, Taleo Enterprise (OTAC) 23D
Oracle updated: 15 Oct 2026 · Source: Oracle Cloud Readiness

Executive Summary

The 26D release for Talent Management introduces a range of enhancements across modules such as Goal Management, Performance Management, and Check-Ins. Key features include AI-assisted goal creation with document uploads, streamlined goal assignments from the Team Activity Center, and improved performance document management with autosave functionalities. Additionally, managers can now calibrate performance ratings during Talent Reviews, enhancing the evaluation process. Customers should be aware of required actions to enable new functionalities and ensure optimal use of these enhancements.

What's New

  • AI-assisted goal creation now allows document uploads for context, enhancing goal suggestions in Goal Management. (Include Document Tool in Goal Creation AI Agent)
  • Managers can assign performance and development goals directly from the Team Activity Center, improving efficiency in goal assignment. (Manager Assigns Performance and Development Goals in Team Activity Center)
  • The Check-Ins Conversation Summary feature now supports uploading media files to generate conversation summaries, enhancing the check-in process. (Upload Media Files to Generate Conversation Summary)
  • Talent Review now allows managers to calibrate performance document ratings during evaluations, improving the review process. (Calibrate Performance Document Ratings in Talent Review)
  • The Manager Coaching Workspace provides evidence-based coaching insights derived from Talent data, helping prioritize coaching conversations. (Identify Coaching Insights for your Team Using Manager Coaching Workspace)
  • The Redwood Mass Action Processes for Performance Documents now allow HR to reopen, restore, and transfer performance documents in bulk, streamlining document management. (Mass Process Performance Document Reopen, Restore, and Transfer Actions)
  • The Team Talent Calibration and Review Workspace has been enhanced to include additional rating actions and data sources, improving performance rating adjustments. (AI Agentic App: Team Talent Calibration and Review Workspace Enhancements For Additional Rating Actions, Data Sources, and Talent Snapshot)
  • The WorkersLOV for anytime feedback now uses the Person Public Notes Data Security Policy to determine available workers, enhancing feedback selection control. (Redwood: Limit Workers Available for Anytime Feedback Based on Person Public Notes Security)

What's Changed

  • The manager name will no longer display for approval tasks that are automatically submitted in the Document Progress drawer, reducing confusion. (Hide Manager Names for Auto-Submitted Approval Tasks in Document Progress)

Deprecations, Retirements and Replacements

  • Learning and Development: The original offering is deprecated after migration, but completed and in-progress assignments remain associated with it. (Bulk migrate self-paced offerings using a REST API)
  • Learning and Development: BI Cloud Connector (BICC) will no longer be supported after 27A, replaced by Learning Catalog and Assignments Data Extraction starting 26C. (Important Actions and Considerations for Learning)
  • Recruiting: Oracle Digital Assistant Fusion Apps templates for Recruiting will be deprecated in November 2026, transitioning to Career Coach. (Transition From Digital Assistant on Recruiting Sites)

Action Required

  • Enable the Goal Level Approval Enabled profile option to support goal level approvals in the Employee Goals Assistant Agent. (Support Goal Level Approvals in the Employee Goals Assistant Agent)
  • Edit the Team Activity Center page in Visual Builder Studio to specify the display order for Assign Development Goal and Assign Performance Goal options. (Manager Assigns Performance and Development Goals in Team Activity Center)
  • Configure the Control Time-Based Autosave Counter on the Provide Requested Feedback Page property to utilize autosave features. (Redwood: Time-Based Autosave for Providing Requested Feedback)
  • Ensure appropriate services for Oracle Applications Platform are deployed to utilize the updated Succession Planning Agent. (Updated Succession Planning Agent to Find Best Matching Candidates for Succession Plans)
