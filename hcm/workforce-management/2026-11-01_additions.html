HCM · Workforce Management: Update digest (additions since the last digest)

Covers: Time and Labor 26D, Workforce Scheduling 26D
Oracle updated: 30 Oct 2026 · Source: Oracle Cloud Readiness

Executive Summary

In the latest 26D release for Workforce Management, significant enhancements have been made across Time and Labor and Workforce Scheduling modules. The Time Profiles Analyst is a new AI agent that simplifies the management of time profiles, allowing users to easily list, identify, and manage profiles. Additionally, Workforce Scheduling introduces several new assistants, including the Work Pattern Template Assignment Assistant, which enables natural language assignments for work patterns, and the Shift Assignment Assistant, which optimizes shift filling by ranking eligible workers. These advancements aim to improve efficiency and user experience, with no immediate actions or deprecations required from customers.

What's New

  • Time and Labor introduces the Time Profiles Analyst, an AI agent that assists users in managing time profiles, including listing profiles and managing overrides. (Time Profiles Analyst)
  • Workforce Scheduling adds the Work Pattern Template Assignment Assistant, allowing users to assign templates using natural language for up to 25 workers. (Work Pattern Template Assignment Assistant)
  • The Shift Assignment Assistant in Workforce Scheduling helps managers find the best workers for shifts by evaluating eligibility and providing ranked recommendations. (Shift Assignment Assistant)
  • Workforce Scheduling's Work Pattern Real Time subject area has been enhanced with new reporting attributes, including Work Pattern Shift Period Type and Work Pattern Work Day Definition. (Workforce Scheduling - Work Pattern Real Time Subject Area Enhancements)

What's Changed

  • The Work Pattern Real Time subject area in Workforce Scheduling has had several existing attributes removed, such as Work Pattern Type Name and Creation Date, while adding new attributes. (Workforce Scheduling - Work Pattern Real Time Subject Area Enhancements)

Deprecations, Retirements and Replacements

None identified in this release.

Action Required

  • Consider creating your own agents using the preconfigured workflows for the Time Profiles Analyst and Shift Assignment Assistant. (Time Profiles Analyst; Shift Assignment Assistant)
  • Plan to deploy the delivered Workforce Schedule Assistant AI agent team template to utilize the new Shift Assignment Assistant features. (Shift Assignment Assistant)
