HCM · Workforce Management: Release digest

Covers: Absence Management 26D, Time and Labor 26D, Workforce Health and Safety 26B, Workforce Scheduling 26D
Oracle updated: 13 Oct 2026 · Source: Oracle Cloud Readiness

Executive Summary

The 26D release for Workforce Management introduces significant enhancements across several modules, including Absence Management, Time and Labor, Workforce Health and Safety, and Workforce Scheduling. Notable improvements include support for partial-day absence durations, enhanced visibility of compensatory plan balances, and a new AI-driven Time-off Assistant for managing time-off requests. Additionally, Time and Labor now features a guided Redwood experience for workday definitions and improved calendar event visibility on time cards. Customers should be aware of the new security role for Absences and Entitlements and the need for setup in various enhancements, particularly those involving AI agents and calendar synchronization.

What's New

  • Absence Management introduces support for partial-day absence durations using fast formulas, enhancing flexibility for absence types with days UOM. (Duration Formula Support for Absence Types With Days UOM and Elapsed Schedules)
  • The Compensatory Plan Balance page now allows for running totals, providing clearer visibility for employees and managers. (Review Compensatory Plan Balances as Running Totals)
  • A dedicated security role for Absences and Entitlements has been added, improving access control for administrators. (Dedicated Security Role for Absences and Entitlements)
  • The Redwood Calendar now includes organization calendar events, allowing synchronization with personal calendars for better scheduling transparency. (Organization Calendar Events in Calendar and Calendar Synchronization)
  • The Leave Agreements page has been enhanced for better management, allowing administrators to search, filter, and manage agreements more effectively. (Enhanced Leave Agreements Page)
  • The Time-off Assistant is now available as an AI agent, streamlining time-off request management for employees and contingent workers. (Time-off Assistant agent runnable duty role for employees and contingent workers)
  • Time and Labor introduces a guided Redwood experience for creating and managing workday definitions, improving usability. (Redwood Experience for Workday Definitions)
  • New filter options in the Redwood Team Schedule enhance visibility into scheduling information by allowing filtering by department, location, job, and event type. (Filter Options in Redwood Team Schedule)
  • Workforce Scheduling now supports the inclusion of break details in schedule imports, improving clarity for workers regarding their breaks. (Include Break Details in Schedule Imports and Worker Notifications)
  • The Shift Assignment Assistant helps managers find the best worker for shifts by ranking eligible workers based on various criteria, streamlining the assignment process. (Shift Assignment Assistant)

What's Changed

  • Absence Planning now sorts search results by name instead of absence status, improving usability for managers. (Default Sorting by Name in Absence Planning)
  • Calendar event enhancements on Redwood time cards now default full-day event entries based on applicable schedules, improving visibility for users. (Enhancements for Calendar Events on Redwood Time Cards)
  • Enhancements for absence integration on Redwood time cards now allow users to delete or withdraw absences based on their status, improving clarity in the approval process. (Enhancements for Absence Integration on Redwood Time Cards)
  • The Manage Time Entries page for line managers now allows for filtering by various criteria, enhancing access to time entry data. (Manage Time Entries page for Line Managers)
  • The View Locked Time Cards action in Time Activity Center enhances visibility into payroll processing by allowing users to monitor locked time cards. (View Locked Time Cards in Time Activity Center)

Deprecations, Retirements and Replacements

None identified in this release.

Action Required

  • Administrators should assign the new Absence and Entitlement Management Duty role to custom roles for improved access control. (Dedicated Security Role for Absences and Entitlements)
  • Enable the profile option ORA_ANC_AGREEMENTS_VBCS_UI_ENABLED to access the enhanced Leave Agreements page. (Enhanced Leave Agreements Page)
  • Setup is required to enable the Time-off Assistant and include it in customer roles for employees or contingent workers. (Time-off Assistant agent runnable duty role for employees and contingent workers)
  • To utilize the new features in Time and Labor, ensure appropriate services for Oracle Applications Platform are deployed and enable necessary profile options. (Enhancements for Calendar Events on Redwood Time Cards; Time Profiles Analyst)
  • Configure minimum staffing levels in the staffing grid to utilize the new scheduling features effectively. (Prioritize Minimum Staffing in Schedule Generation)
