HCM · Common Technologies and User Experience: Release digest

Covers: Common Technologies and User Experience 26D
Oracle updated: 19 Oct 2026 · Source: Oracle Cloud Readiness

Executive Summary

In the 26D release for Common Technologies and User Experience, several important updates have been made across various modules. The Sign In page has been updated to provide tailored experiences based on SSO configurations, while AI Agent Studio has introduced new features for managing AI unit budgets, integrating CI/CD processes, and enhancing workflow testing. Additionally, contextual announcement banners can now be configured on Redwood pages, and users must enroll in multifactor authentication if they are part of new environment families. The deprecation of certain Business Intelligence View Objects also requires attention to ensure continued functionality.

What's New

  • Users can now record issues on Redwood pages using the Record Issue feature in the Settings and Actions menu, enhancing troubleshooting efficiency for help desk teams. (Record issues on Redwood pages)
  • AI Agent Studio introduces the ability to manage AI unit budgets and monitor consumption, allowing administrators to set budgets and configure alerts. (Manage AI unit budget, consumption, and controls)
  • New integration with CI/CD processes in AI Agent Studio enables teams to manage application deployments through a controlled lifecycle, maintaining artifacts in Git repositories. (Integrate AI Agent Studio applications and workflows with CI/CD)
  • The AI Agent Studio Testing and Lifecycle Automation Suite (ATLAS) now supports regression testing of workflows, allowing for repeatable validation of artifacts. (Test and validate AI Agent Studio workflows with ATLAS)
  • Oracle Fusion Claw is introduced as a governed runtime capability for creating autonomous outcomes through AI-driven automation, allowing users to define outcomes in natural language. (Use Oracle Fusion Claw to create autonomous outcomes with agentic applications)
  • Instruction guardrails can now be added to large language model (LLM) nodes in workflows to improve response reliability and safety. (Add instruction guardrails to LLM nodes)
  • AI Agent Studio now includes an AI Guidance node for creating or retrieving insights and recommendations based on business contexts. (Configure an AI guidance node in a workflow)
  • Users can create and manage Ask Oracle plugins in AI Agent Studio, extending its capabilities with specialized business expertise. (Create and manage Ask Oracle plugins)
  • Contextual announcement banners can now be enabled on Redwood pages to convey important information, requiring configuration through Visual Builder Studio. (Contextual announcement banner on Redwood pages)
  • The Redwood appearance editor now allows overriding accessibility checks for custom colors, enabling the use of brand colors as primary theme colors. (Redwood appearance editor: Override accessibility checks and use as primary color)
  • New functionality in Oracle Transactional Business Intelligence (OTBI) expands data and business analysis capabilities, automatically available after the update. (What's notable and different in Oracle Transactional Business Intelligence)

What's Changed

  • The Sign In page for Oracle Fusion Cloud Applications has been updated to provide different layouts based on whether users are on federated or non-federated SSO. (Changes in Oracle Fusion Cloud Applications Sign In page)

Deprecations, Retirements and Replacements

  • Certain Business Intelligence View Objects (BIVOs) are deprecated and no longer available for extraction using BI Cloud Connector. Users should review the Deprecated and New BI View Objects spreadsheets to update their BICC tasks accordingly. (Deprecated and new BI view objects in Oracle BI Cloud Connector)
  • Oracle Digital Assistant skills will be discontinued on November 21, 2026, requiring migration plans for affected users. (IMPORTANT Actions and Considerations)

Action Required

  • Users must enroll in multifactor authentication (MFA) upon first sign-in if they are part of new environment families created from 25D onwards. (Multifactor authentication (MFA))
  • Ensure security administrator grants permission to record issues on Redwood pages to utilize the new feature effectively. (Record issues on Redwood pages)
  • Ensure access to AI Agent Studio to utilize new features related to AI unit management, CI/CD integration, and workflow testing. (Manage AI unit budget, consumption, and controls; Integrate AI Agent Studio applications and workflows with CI/CD; Test and validate AI Agent Studio workflows with ATLAS)
  • Configure contextual announcement banners on Redwood pages through Visual Builder Studio to communicate important information. (Contextual announcement banner on Redwood pages)
  • Override accessibility checks in the Redwood appearance editor requires configuration in a sandbox environment. (Redwood appearance editor: Override accessibility checks and use as primary color)
