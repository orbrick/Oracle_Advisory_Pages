ERP · Project Management: Release digest

Covers: Project Management 26D
Oracle updated: 24 Sep 2026 · Source: Oracle Cloud Readiness

Executive Summary

In the 26D release of Project Management, significant advancements include the introduction of the Project Planning Workspace and the Billing Operations Workspace, both leveraging AI to streamline project initiation, budget planning, and billing processes. The Project Planning Workspace enables users to generate proposals and create structured project plans, while the Billing Operations Workspace focuses on billing readiness and dispute resolution. Customers are required to opt in to new features and ensure proper setup to utilize these enhancements effectively. Additionally, there are important actions regarding the deprecation of Digital Assistant skills and templates, which will be desupported on November 21, 2026, urging users to transition to Oracle AI Agent Studio.

What's New

  • The Project Planning Workspace introduces AI-powered capabilities for project initiation and budget planning, allowing users to generate proposals and create structured project plans. (Project Planning Workspace for project initiation and budget planning)
  • The Billing Operations Workspace provides a unified experience for billing readiness and dispute resolution, streamlining billing processes with policy-driven automated actions. (Billing Operations Workspace for billing readiness and dispute resolution)
  • Project Financial Control Agents enhance financial oversight by providing insights into project costs and reconciliation through guided interactions. (Project Financial Control Agents)
  • The Ingest Contract Documents Using AI feature allows users to efficiently convert existing contract documents into contract records with less manual effort. (Ingest Contract Documents Using AI)
  • Payroll encumbrance distribution to Projects allows organizations to track payroll-generated encumbrances as project labor commitments, improving budget visibility. (Payroll encumbrance distribution to Projects)
  • Labor schedule management pages have been redesigned to improve user experience and efficiency, offering enhanced search and filtering capabilities. (Updated labor schedule management pages)
  • The new feature for tracking progress with task output quantities enables project managers to calculate task percent complete and supports billing. (Track progress with task output quantities)
  • Additional accounting sources for non-project labor costs improve the accuracy of accounting policies by incorporating more worker assignment attributes. (Additional accounting sources for non-project labor costs)

What's Changed

  • Deletion of project intercompany and interproject invoices in Payables is now restricted when corresponding invoices are in Accepted status in Project Contracts, preventing data inconsistencies. (Prevent deletion of project intercompany and interproject invoices pending completion in Payables)
  • This update includes several bug fixes affecting application behavior, such as the removal of Basic Authentication for DocuSign and support for pending workers in employment contracts. (Selected Contracts Bug Fixes in This Update)

Deprecations, Retirements and Replacements

  • Digital Assistant skills and templates will be desupported on November 21, 2026, with a recommendation to transition to Oracle AI Agent Studio. (IMPORTANT Actions and Considerations)

Action Required

  • Customers must review the New Features work area and opt in to any features delivered disabled using specific privileges and steps outlined in the update. (Optional Uptake of New Features (Opt In))
  • Ensure proper setup for the Project Planning Workspace, Billing Operations Workspace, and Payroll encumbrance distribution features to utilize their capabilities effectively. (Project Planning Workspace for project initiation and budget planning; Billing Operations Workspace for billing readiness and dispute resolution; Payroll encumbrance distribution to Projects)
