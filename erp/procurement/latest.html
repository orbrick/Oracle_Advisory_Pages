ERP · Procurement: Release digest

Covers: Procurement 26D, Self Service Procurement 26D
Oracle updated: 2 Oct 2026 · Source: Oracle Cloud Readiness

Executive Summary

The 26D release for Procurement and Self Service Procurement brings a host of new features aimed at enhancing operational efficiency and user experience. Key modules such as Supply Chain Orchestration now support intra-organizational material transfers, improving inventory utilization and fulfillment flexibility. Additionally, enhancements in collaboration messaging streamline supplier interactions, while new REST resources facilitate better integration capabilities. Customers are encouraged to review and opt in to new features to fully leverage these updates, as some functionalities require specific setup actions. Notably, the original Redwood supplier search feature will be deprecated in the upcoming 27B update, necessitating a transition to the new tax identifier search feature introduced in this release.

What's New

  • Supply Chain Orchestration now allows intra-organizational material transfers for supply requests, enhancing fulfillment flexibility and inventory utilization. (Enable intra-organizational material transfers for transfer supply requests originating from Self Service Procurement; Enable intra-organizational material transfers for transfer supply requests originating from Self Service Procurement)
  • New inventory on hand striping attributes for manual transfer supply requests ensure that transfer orders reflect required inventory characteristics, improving fulfillment precision. (Inventory on hand striping attributes for manual transfer supply requests in Supply Chain Orchestration; Inventory on hand striping attributes for manual transfer supply requests in Supply Chain Orchestration)
  • Purchase requisitions from min-max planning can now be routed through the procurement approval workflow, streamlining replenishment processes. (Route inventory min-max planning and PAR replenishment purchase requests through procurement approval workflow; Route inventory min-max planning and PAR replenishment purchase requests through procurement approval workflow)
  • Minimum remaining shelf life support is now available in back-to-back fulfillment flows, ensuring inventory meets shelf life requirements during transfers. (Support minimum remaining shelf life for back-to-back transfer and on hand flows; Support minimum remaining shelf life for back-to-back transfer and on hand flows)
  • Collaboration Messaging now derives supplier site from invoice account numbers, ensuring invoices are routed correctly for GHX inbound invoices. (Derive supplier site from invoice account numbers)
  • Brazilian organizations can now receive additional electronic fiscal documents through Collaboration Messaging, extending existing SEFAZ capabilities. (Receive Brazil electronic fiscal invoices for services and utilities)
  • The Procurement Spend Command Center has been introduced to help identify maverick spend and agreement leakage, providing insights into spend drivers. (Procurement Spend Command Center)
  • New REST resources have been introduced to simplify integration with external systems in Oracle Fusion Cloud Procurement, enhancing overall connectivity. (Integrate and extend procurement using REST resources; Integrate and extend procurement using REST resources)
  • The Procurement Request Concierge allows users to describe their needs in natural language, directing them to the appropriate procurement tasks. (Procurement Request Concierge)
  • A new centralized Catalog Administration landing page has been introduced for catalog administrators, streamlining management tasks. (Manage catalog administration tasks using a new user experience)

What's Changed

  • The Intake Request Creation Assistant has been enhanced with new capabilities, including automatic UOM validation and AI-generated request summaries, improving data accuracy and user experience. (Intake Request Creation Assistant - Create and review with enhanced features)
  • Lifecycle management for intake requests has been improved, allowing reviewers to return requests with reasons and enabling requesters to change templates for draft or returned requests. (Enhance lifecycle management for intake requests)
  • Detailed error messages are now displayed in requisition approvals, providing clearer guidance on approval issues. (Display detailed error messages in requisition approvals)

Deprecations, Retirements and Replacements

  • The original Redwood supplier search feature will be removed in update 27B, replaced by the new feature that allows searching for suppliers using tax identifiers introduced in release 26D. (IMPORTANT Actions and Considerations)

Action Required

  • Customers must review and opt in to new features via Navigator > My Enterprise > New Features, especially those requiring setup or configuration. (Optional Uptake of New Features (Opt In); Optional Uptake of New Features (Opt In))
  • Enable the profile option 'Redwood Page for Supplier Portal Invoices and Payments Enabled' to use the new user experience for invoices in the Supplier Portal. (View invoices from purchase orders in Supplier Portal using a new user experience)
  • Set the Min-Max Replenishment Reorder Approval profile option to ensure purchase requisitions are routed through the approval workflow. (Route inventory min-max planning and PAR replenishment purchase requests through procurement approval workflow; Route inventory min-max planning and PAR replenishment purchase requests through procurement approval workflow)
  • Enable the profile option Redwood Catalog Setup Pages Enabled to access new catalog management features. (Manage catalog administration tasks using a new user experience; Manage catalogs; Manage smart forms)
