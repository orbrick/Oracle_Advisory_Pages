ERP · Financials: Release digest

Covers: Accounting Hub 26A, Financials 26D, Self Service Financials 26D
Oracle updated: 19 Oct 2026 · Source: Oracle Cloud Readiness

Executive Summary

This release of Financials, covering modules such as Accounting Hub, Financials, and Self Service Financials, brings a wealth of new capabilities aimed at enhancing usability and operational efficiency. Key highlights include the Advanced Event Model Configuration in Accounting Hub, which allows for better transaction organization, and various enhancements in the Expenses Agent for improved expense reporting. Customers are required to opt in to new features to enable them, ensuring they can leverage the latest functionalities effectively. Additionally, several usability improvements have been made to streamline processes and enhance user experience.

What's New

  • Accounting Hub introduces Advanced Event Model Configuration, enabling users to define multiple event classes and process categories within a single application, enhancing transaction organization and journal categorization. (Advanced Event Model Configuration in Accounting Hub)
  • The Financials module now allows the system to derive the pay site for GHX inbound invoices using B2B Account Number setup in Collaboration Messaging, streamlining invoice processing. (Derive supplier site from invoice account numbers)
  • Organizations in Brazil can now electronically receive additional fiscal documents, including NFS-e, NFCom, and NF3-e, through Oracle Collaboration Messaging, simplifying compliance. (Receive Brazil electronic fiscal invoices for services and utilities)
  • The Ledger Agentic Application introduces a governed runtime execution layer, enhancing accounting operations by enabling autonomous execution of delegated tasks. (Ledger Agentic Application)
  • The Payables Period Close Workspace centralizes the Payables close process, allowing teams to manage exceptions and prioritize actions effectively. (Payables Period Close Workspace)
  • The Cash Processing Agent now supports bank statement reconciliation with a conversational interface, improving visibility into unreconciled transactions and exceptions. (Cash Processing Agent for bank statement reconciliation)
  • The Expenses Agent now supports itemization and attendee management for expense reporting, streamlining submissions and ensuring compliance with company policies. (Expenses Agent for itemization and attendees)
  • The Budget Adjustment Assistant validates budget transfers against policies and routes adjustments for approval, enhancing accountability in budget management. (Budget Adjustment Assistant with policy and approvals)
  • The Tax Point Date Adjustment process identifies invoices with mismatched dates for compliance with Poland's KSeF system, improving VAT reporting accuracy. (Tax point date adjustment for Polish e-Invoice compliance)
  • The new Redwood Supplier Portal experience enhances supplier navigation and invoice entry, replacing classic pages with a more user-friendly interface. (Redwood Supplier Portal Invoice Submission and Status Tracking)

What's Changed

None identified in this release.

Deprecations, Retirements and Replacements

  • Classic View Invoices, View Payments, Create Invoice, and Create Invoice without PO entry points are no longer available after enabling the Redwood experience. (Redwood Supplier Portal Invoice Submission and Status Tracking)

Action Required

  • Customers must opt in to new features delivered disabled in Oracle Cloud Applications by navigating to the New Features work area and selecting desired features to enable. (Optional Uptake of New Features (Opt In); Optional Uptake of New Features (Opt In); Optional Uptake of New Features (Opt In))
  • For the Budget Adjustment Assistant, customers should log a Service Request to enable this feature and contact Oracle Support for access. (Budget Adjustment Assistant with policy and approvals)
  • Users must set up required security roles and privileges to access new assistants and features introduced in this release, such as the Reversal and Rebilling Assistant and the Partner Contribution Replenishment Assistant. (Reversal and Rebilling Assistant; Partner Contribution Replenishment Assistant)
